🏆 Проекты (Projects)

### Проект № 1. 🎠 Игровой комплекс для благоустройства города

**Задача:**  
Разработать и подготовить к производству многофункциональный игровой комплекс для детской площадки в городском парке. Комплекс должен включать горки разной высоты, карусели, лестницы, мостики и игровые панели.

**Решение:**
- Создал 3D-модель всего комплекса в SolidWorks, проработал все узлы и подготовил к производству.
- Разработал металлический каркас (сварные конструкции)
- Спроектировал деревянные элементы (фанерные детали для горок, лестниц, площадок)
- Выполнил раскрой фанеры для ЧПУ-станка — оптимизировал расположение деталей для экономии материала (~12% экономии)
- Подготовил полный пакет чертежей в Компас-3D для производства и монтажа

**Результат:**  
Комплекс успешно изготовлен и установлен. Прошел все проверки на безопасность. Получил положительные отзывы от заказчика.

**Инструменты:** SolidWorks, Компас-3D, ЧПУ-раскрой (Aspire)

### Проект № 2. 🚪 Межквартирные двери (индивидуальный заказ)

**Задача:**  
Разработать чертежи и 3D-модели межкомнатных дверей для частного заказа. Требовалось изготовить дверь нестандартного размера с единым дизайнерским решением.

**Решение:**
- Создал параметрические 3D-модели дверей в SolidWorks для быстрой адаптации под разные размеры
- Разработал чертежи в Компас-3D для производства (деталировка коробок, полотен, наличников)
- Подготовил раскрой фанеры и МДФ для ЧПУ-станка с нулевым зазором между деталями

**Результат:**  
Изготовлена дверь с точным соответствием размерам и дизайну. Заказчик отметил высокое качество подгонки деталей и минимальное количество отходов материала.

**Инструменты:** SolidWorks, Компас-3D, ЧПУ-раскрой

### Проект №3 🎡 Карусель для детского парка

**Задача:**  
Разработать концепцию и рабочую документацию для карусели на 8 посадочных мест. Конструкция должна быть безопасной, надежной и соответствовать ГОСТам для детского оборудования.

**Решение:**
- Разработал 3D-модель карусели в SolidWorks с расчетом нагрузок на центральную ось и опоры
- Спроектировал металлический каркас, сиденья и поручни
- Выполнил чертежи в Компас-3D для изготовления металлических и деревянных деталей
- Подготовил файлы для ЧПУ-раскроя фанерных сидений, площадки и декоративных элементов

**Результат:**  
Карусель изготовлена и установлена. Конструкция выдерживает заявленные нагрузки, успешно прошла испытания.

**Инструменты:** SolidWorks, Компас-3D, прочностные расчеты (ручной), ЧПУ-раскрой (Aspire)
